Kasm: Rust SDK for Ableton Live Max4Live MIDI Manipulation

Kasm is a modern SDK for Ableton Live's Max4Live, empowering developers to build custom devices using the Rust programming language. Unlock new creative possibilities for live MIDI manipulation, generative music, and advanced audio workflows.

  • Write Max4Live devices in Rust for performance and safety
  • Manipulate live MIDI streams in real time
  • Integrate with Ableton Live for seamless music production
  • Open source, developer-friendly, and extensible

Why Kasm?

Kasm bridges the gap between modern systems programming and music technology. Whether you're a musician, audio developer, or creative technologist, Kasm lets you:

  • Prototype new MIDI effects and instruments
  • Leverage Rust's speed and reliability
  • Expand Ableton Live with custom, high-performance devices

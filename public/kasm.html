pitch The MIDI note number (e.g., 60 is Middle C, 90/100/103 are higher notes).
start_time When the note begins, in beats (relative to the clip's start).
duration How long the note lasts, in beats.
velocity How hard the note is played (0–127): higher = louder.
mute 1 = muted note, 0 = active note.
probability A float between 0 and 1, showing the chance this note will play (1 = always, 0.5 = 50%).
velocity_deviation Specifies variability in velocity for each triggering, often 0 unless randomization used.
release_velocity The velocity value sent when the note is released (key is lifted); often relevant for expressive playing.

More about Kasm...

  • Rust-to-WASM compilation pipeline: Write high-performance MIDI algorithms in Rust, deploy as Max4Live devices
  • MIDI abstraction layer: Clean APIs for notes, velocity, CC messages, timing
  • Build tools & templates: Go from Rust code to working M4L device
  • Web browser WebMIDI test harness: Run and hear your Rust WebAssembly in Chrome/Firefox/Safari/Edge
  • Full example implementations: Emanator plugin with 15 algorithms

Example Devices & Features

  • MIDI output version: Sends MIDI data to Max4Live midiout
  • Ableton MIDI Generator: Creates Note dictionary objects
  • MIDI Transformation: Adapts existing Note dictionary objects
  • Continual musical key & chord detection
  • Live note sequence detection for triggering scene changes, DMX lighting, etc.
  • Virtual tape loop buffering, replay, overlay harmony/counterpoint

Who Is This For?

Developers who want to build professional MIDI tools without the limitations of traditional Max4Live development. Whether you’re creating commercial plugins or experimental instruments, Kasm handles the Rust-to-Live integration complexity so you can focus on your algorithms.

Requirements

  • Ableton Live 12.2 (or later) with Max4Live (uses new V8 engine)
  • Or you can use this browser version with Ableton instead

What You'll Learn

  • Passing inlet parameters from JS to Rust
  • Rust code calling Max4Live outlet functions
  • Max console debug post() messages from Rust
  • Manipulating live notes on-the-fly with Rust/WebAssembly

How Does Kasm Work?

  1. Rust Code Layer: MIDI/Audio DSP logic compiled as WebAssembly
  2. JavaScript Bridge Layer: Loads WASM bytecode, sets up parameter marshalling for Max4Live
  3. Max4Live Layer: V8 JavaScript engine with example .amxd device showing two-way communication with Rust
  • Base64 Decoding: Custom atob() for Max4Live
  • WASM Compilation: Direct compilation from decoded binary
  • Function Export: Caching mapped Rust functions for JS
  • getStringFromWasm: Convert WASM memory strings to JS strings

Easy Build & Update

  • npm install
  • npm run build
  • Copy kasm_WASM_rust_obs.js into any 'v8' Max4Live object
